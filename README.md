#  Restaurant Order – 虛擬實境英語學習遊戲

本專案是一個 **結合虛擬實境與生活場域** 的英語學習系統 Demo。  
學習者在速食店情境中透過 **點餐互動** 來練習英文，並在遊戲中獲得即時回饋，提升學習動機與投入感。  

---

##  系統特色
- 沉浸式 **VR 餐廳環境**（Unity 開發）  
- 任務導向：完成顧客點餐任務  
- 即時回饋（正確完成顯示 ✅ 綠色勾勾）  
- 提升 **學習動機、專注力與心流體驗**  

---

##  研究目的
- 透過 VR 教學提升學習者的 **專注力與參與度**  
- 提供更貼近真實情境的 **英語學習方式**  
- 分析學習者在 VR 學習中的 **互動與心流經驗**  

---

##  遊戲玩法
1. 啟動系統後進入餐廳場景。  
2. 閱讀顧客的點餐需求。  
3. 正確選擇餐點並完成訂單。  
4. 完成所有顧客訂單後遊戲結束。  

---

##  技術
- **Unity** 遊戲引擎  
- 餐廳場景建模與角色互動  
- 使用者介面與任務流程設計
